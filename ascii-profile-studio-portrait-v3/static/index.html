ASCII Profile Studio Seu perfil, totalmente editável.
● 100% local

Crie seu README em estilo terminal.

Use a sua foto, controle o ASCII, personalize qualquer campo e exporte SVG nítido. Prévia em tempo real.

01

Identidade e fotografia

A foto original e uma versão sem fundo estão incluídas em assets/. Uploads ficam somente no computador.

Enquadramento

Arraste sua foto para mover o recorte. Ajuste o zoom e a posição manualmente se preferir.

02

Campos e seções

Troque "Uptime" por qualquer informação. Arraste as alças ⠿ para reorganizar campos e seções; os botões ↑ ↓ também funcionam.

03

Arte ASCII

No modo de retrato detalhado, os caracteres recebem tons individuais e continuam 100% editáveis como texto no SVG. Use PNG transparente e uma foto de rosto visível para melhorar a semelhança.

04

Layout e aparência

Cores — modo escuro

Cores — modo claro

Para destacar parte de um valor, escreva [[+123++]] (verde) ou [[-34--]] (vermelho). As cores acima serão usadas de verdade no SVG.

05

GitHub e publicação

Atualiza dados públicos do seu usuário.

Campos automáticos usam {{github.public_repos}}, {{github.followers}}, {{github.stars_received}} e {{github.forks_received}}. Totais que a API não oferece ficam indisponíveis — não inventamos commits ou linhas de código.

O projeto também funciona pelo terminal com python generator.py.
